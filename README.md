# Mercor AI Evaluation Portfolio

**Damilare Oderinwale | Mathematics Expert · AI Generalist · AI Evaluator**

This repository contains independent demonstration projects showing a structured approach to evaluating AI-generated mathematical responses.

## Projects
- `mathematics-evaluation/evaluate_response.py` — score a response against a transparent evaluation rubric.
- `response-comparison/compare_responses.py` — compare two candidate responses using criterion scores.
- `evaluation-rubric/rubric.md` — evaluation criteria and scoring guidance.
- `sample-data/sample_evaluations.json` — illustrative sample evaluation records.

## Important scope note
These are self-directed portfolio demonstrations. They are not evidence of paid AI-evaluation employment, production annotation work, or work for a named AI company. Scores are human-entered assessments; the scripts do not independently prove mathematical correctness.

## Run
Requires Python 3.8+ and no third-party packages.

```bash
python mathematics-evaluation/evaluate_response.py
python response-comparison/compare_responses.py
```

## Evaluation approach
The rubric considers:
1. Mathematical correctness (40%)
2. Reasoning and validity (25%)
3. Instruction adherence (15%)
4. Clarity and communication (10%)
5. Completeness (10%)

The evaluator should independently verify calculations and provide evidence for each score.
